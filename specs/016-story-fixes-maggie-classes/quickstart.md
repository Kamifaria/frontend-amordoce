# Quickstart: Testing Dialogue Changes

1. Run the Next.js development server:
   ```bash
   npm run dev
   ```
2. Navigate to `/game`.
3. Play through Episode 1.
4. Verify the classroom schedule transitions.
5. In the notebook search phase, navigate to the Photography Room (Galpão) to meet Maggie and test her dialogue branches.
6. Verify that visiting the Art Room and picking the notebook successfully transitions to the notebook delivery sequence without freezing.
