# Quickstart: Closet, Shop & Gold Testing

1. Run the server:
   ```bash
   npm run dev
   ```
2. Navigate to the Map, click "Loja de Roupas" (cost 10 PA).
3. Try to purchase a locked dark outfit item.
4. Go to the Closet/Wardrobe tab on the home/lobby page.
5. Verify that bought outfits can be equipped, updating Veronica's avatar.
6. Play the Guitar Minigame, check that finishing awards Gold to your player balance.
